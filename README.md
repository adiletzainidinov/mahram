# Знай, кто тебе махрам

Мобильная HTML/CSS страница, объясняющая понятие «махрам» в исламе.

## Структура файлов

```
Mahram_Html/
├── index.html   — главная страница
├── styles.css   — все стили (переменные, компоненты, адаптив)
└── README.md    — этот файл
```

## Как открыть

Откройте `index.html` в любом современном браузере — файл работает без сервера.

## Как встроить в большой проект

**Вариант 1 — простое встраивание:**
1. Скопируйте содержимое `<body>` из `index.html` в нужное место.
2. Подключите `styles.css` в `<head>` основного файла:
   ```html
   <link rel="stylesheet" href="path/to/styles.css">
   ```
3. Убедитесь, что в `<head>` есть:
   ```html
   <meta name="viewport" content="width=device-width, initial-scale=1.0">
   ```

**Вариант 2 — изолированное встраивание (без конфликтов стилей):**
1. Добавьте класс-обёртку в корень страницы, например `.mahram-block`.
2. Добавьте этот класс как префикс ко всем селекторам в `styles.css`.
3. Или используйте Shadow DOM / `<iframe>` для полной изоляции.

## Технологии

- Чистый HTML5 и CSS3
- Без JavaScript
- Без внешних зависимостей, CDN и изображений
- Mobile-first, адаптивен от 320px до desktop

## Адаптивность

| Ширина | Поведение |
|--------|-----------|
| < 360px | Компактный мобильный вид |
| 360–767px | Стандартный мобильный вид, секции вертикально |
| 768px+ | Две секции рядом (сетка) |
| 920px+ | Полный desktop вид, max-width 920px |
